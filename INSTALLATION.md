# 🔧 Excel to VCF Converter - Installation & Setup Guide

## 📦 Installation Options

### Option 1: Using Python (Recommended for Developers)
1. **Install Python 3.6+** from python.org
2. **Download** the application files
3. **Install dependencies**:
   ```bash
   pip install -r requirements.txt
   ```
4. **Run the application**:
   ```bash
   python excel_to_vcf_converter.py
   ```

### Option 2: Using Executable (Easiest for End Users)
1. **Download** `ExcelToVCFConverter.exe`
2. **Double-click** to run
3. **No installation required** - runs immediately

### Option 3: Using Batch File
1. **Download** all application files
2. **Double-click** `run.bat`
3. **Follow on-screen instructions**

## 🎯 System Requirements

### Minimum Requirements:
- **Windows 7 or later**
- **2GB RAM** (4GB recommended)
- **50MB free disk space**

### For Python Version:
- **Python 3.6+**
- **pip package manager**
- **Internet connection** (for one-time dependency install)

## 📋 File Structure

After installation, you should have:

## 🚀 First Time Setup

## ⚠️ Troubleshooting Installation

### Common Issues:

**"Python not found"**:
- Install Python from python.org
- Add Python to PATH
- Use executable version instead

**"Module not found"**:
- Run: `pip install -r requirements.txt`
- Check Python version compatibility
- Use virtual environment

**"Application won't start"**:
- Check Windows version (7+)
- Run as Administrator
- Disable antivirus temporarily

**"File access denied"**:
- Check folder permissions
- Run from different location
- Disable read-only attribute
